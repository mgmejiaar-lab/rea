# Cápsula: Prueba

Abierta: 2026-10-14 · id: cd9090fc-141e-42c6-95b6-f62d3f1f7ad8

## Objetivo

Dejar REA (github.com/morluto/rea, "Reverse Engineer Anything") utilizable en este proyecto para que el usuario pueda pedirle al agente que haga ingeniería inversa de una app o sitio web y se la explique.

## Alcance

- REA es un CLI/MCP de ingeniería inversa, NO una app web: nunca va a aparecer nada en la Vista Previa del Taller (confirmado: sin script "dev", "start" usa stdio, no abre puerto).
- Usuario autorizó (2026-10-14/15): NO compilar el repo fuente para uso normal (basta el paquete publicado en npm); SÍ registrar REA como servidor MCP de Claude Code vía `rea setup` (toca `~/.claude.json` y `~/.claude/skills/`, fuera de esta carpeta, con respaldo automático de REA).
- No autorizado: registrar Codex, instalar Hopper, ni cambiar límites de memoria/Docker del servidor (eso se investigó para OTRA aplicación, no para este proyecto).

## Avances comprobados

- Intento de compilar desde fuente (`npm run build:cached`) falla por OOM: este contenedor tiene cgroup con límite de 2 GiB de RAM (`/sys/fs/cgroup/memory.max`), `tsc` muere (exit 137, oom_kill confirmado en memory.events) incluso limitando `--max-old-space-size=1536`. No se volvió a reintentar tras el 2º fallo.
- Alternativa que SÍ funciona: `npx -y rea-agents@latest` (paquete publicado, ya compilado) corre bien aquí — probado `--help`, `doctor`, `capabilities`.
- `npx rea-agents@latest setup --client claude_code --yes` se aplicó con éxito: `configured_claude_code` (MCP añadido a `/datos/home/.claude.json`, respaldo en `/datos/home/.claude.json.rea.backup`) e `installed_skill` (skill "reverse-engineer-anything" instalado en `~/.claude/skills/`, 207 herramientas, estado "aligned"). El skill ya aparece disponible en esta misma sesión.
- Motores nativos (Ghidra/IDA/Hopper/jadx) NO están configurados en este entorno — análisis de binarios nativos/APK con decompilador no disponible todavía. Análisis estático (artefactos, PE/.NET managed, JavaScript/Electron) sí disponible sin motor adicional.

## Pendientes

- El registro MCP en `~/.claude.json` puede requerir reiniciar Claude Code para que otras sesiones vean las herramientas de REA activas — aún no se probó un análisis real end-to-end con el agente usando REA.
- Falta que el usuario indique una app/web objetivo concreta para hacer una prueba real de ingeniería inversa con evidencia.
- Si en el futuro quiere análisis nativo (binarios/APK con decompilador), falta instalar Ghidra/IDA/Hopper por separado (bring-your-own) y configurar las variables de entorno correspondientes.

## Bloqueos

- Compilar el repo fuente de REA en esta carpeta sigue bloqueado por el límite de memoria de 2 GiB del contenedor (no es un bug del código; es un límite del entorno). No es necesario para el objetivo actual.
